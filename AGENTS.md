# Инструкции агенту

Один файл. Читать до правок карты, API и запуска. Интерфейс на русском. Не открывать заново выбор из трёх макетов: направление уже выбрано.

## Направление

Пользователь выбрал дословно: «берем @FleetMonitor/design-demos/01-gallery-dark.html». Это записано в `design-demos/direction-approved.md`.

Рабочее место — `/map`: карта на весь экран, тёмная полоса 48px, снизу лента 160px. Журнал и сводка остаются, но не равны карте по весу. Макеты 02 и 03 не переносить в React.

Не возвращать: фиолетовый градиент, эмодзи-иконки, акцент `#2563eb`, светлую шапку, тост как основной сигнал тревоги, счётчик «в депо». Тайлы только Esri World Street Map, `detectRetina: false`. Не инвертировать `.leaflet-tile-pane` и не ставить CARTO: там дыры или водяной знак про ключ.

## Запуск, который реально кормит карту

Пустой список и надпись «не удалось загрузить машины» — это не баг вёрстки. Браузер спросил `/api/vehicles`, а ответила HTML-страница Vite.

1. `docker compose up -d postgres redis rabbitmq`. Не собирать образы backend и frontend без корневого `.dockerignore`: контекст утащит `node_modules`.
2. Backend на хосте читает `backend/.env` с портами compose, не с именами контейнеров: Postgres `127.0.0.1:15432`, Redis `127.0.0.1:16379`, RabbitMQ `127.0.0.1:5672`, `PORT=3000`.
3. `prisma migrate deploy` и `prisma generate` из `backend/`, схема `prisma/schema.prisma`.
4. `nest start --watch` из `backend/`.
5. Симулятор на хосте: свой venv и `python main.py`. Адрес по умолчанию `amqp://guest:guest@localhost:5672`. Хост `rabbitmq` — только внутри compose.
6. Frontend: `CHOKIDAR_USEPOLLING=1` на диске Windows. Прокси `/api` и `/socket.io` уже в `frontend/vite.config.ts`, цель `http://127.0.0.1:3000`. Не создавать `frontend/.env` с `VITE_API_URL`: браузер уйдёт мимо прокси.
7. Машины появляются только после GPS. Пустая база — это «пока нет машин», не ошибка загрузки.

Проверка: `curl http://127.0.0.1:5173/api/vehicles` возвращает JSON-массив. Ответ `text/html` значит, что прокси не подхватился.

На `/mnt/c` и `nest --watch`, и Vite без polling не видят сохранения. После правки backend процесс перезапустить. Не поднимать второй Vite на 5173.

## Ловушка конфига Vite

Vite берёт `vite.config.js` раньше `vite.config.ts`. `tsc -b` раньше писал js рядом с ts, и прокси молча пропадал. Сейчас `tsconfig.node.json` кладёт emit в `frontend/node_modules/.tmp`. Не возвращать `vite.config.js` в корень `frontend/`. Исходник один: `vite.config.ts`.

## Контракт карты

Не выдумывать машины, квитанции, геозоны и историю длиннее ответа API.

- Внимание: последнее событие `CRITICAL`, либо офлайн с `lastSeen` не старше 5 минут. Машина без единой точки — не внимание.
- Слова: критическое — «смотри сейчас», офлайн — «нет связи», скорость 0 — «стоит», иначе «едет». Критическое важнее движения.
- «Скрыть» помнит id события до закрытия вкладки. Новое критическое показывает красную строку снова. API квитирования нет.
- Порядок ленты: критические по свежести события, недавний офлайн, едет, стоит, давний офлайн. Внутри едет/стоит/давний офлайн порядок по номеру, `localeCompare('ru')`, чтобы GPS не перемешивал ленту.
- Счётчики: в сети, без связи, критических. Прочерк, пока список не пришёл. Нуля «в депо» нет.
- Поток: «поток: живой» или «поток: нет связи» по сокету.
- Клик по номеру или маркеру центрирует машину один раз. Повторные GPS карту не тащат. Escape снимает выбор и не даёт автовыбору вернуться. Escape в непустом поиске чистит только поиск.
- Автовыбор первой видимой критической машины один раз и сразу на место события.
- Строка события в карточке — кнопка «показать место». Кольцо стоит на `lat`/`lng` события. Машина остаётся на своей точке.
- След — `gpsPoints` из `GET /api/vehicles/:id` (до 10, в ответе сначала новые) плюс живая точка. Пока машина не выбрана, линии нет.
- `isOnline` на клиенте брать из поля API, не из факта «`state` не пустой». Пустой Redis больше не означает пустой `state`.

Офлайн на клиенте: 15 секунд без новой точки. Серая точка без тика курса. Возраст в карточке — «нет связи · N мин».

Запрос, который ждёт массив или `items`, обязан бросать ошибку, если пришёл не тот тип. Иначе HTML от Vite проходит как успешный ответ, и страница падает на `.forEach`.

## Что не рисовать без модели

Квитирование с именем и временем, геозоны, след длиннее 10 точек, задания, ETA, тахограф, топливо, чат с водителем. `WebhookLog` в интерфейсе не показан. Водитель — строка на машине, не отдельная сущность.
